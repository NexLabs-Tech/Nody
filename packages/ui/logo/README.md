# Nody logo drafts

These are original, editable SVG explorations for the Nody workspace UI.

The folder also contains high-resolution PNG exports: `nody-light.png`, `nody-dark.png`, `nody-icon-light.png`, and `nody-icon-dark.png`. The Logos page previews and links all PNG and SVG assets.

- `nody-symbol.svg` — blue app mark with a parent page and two child blocks.
- `nody-symbol-mono.svg` — monochrome mark for neutral contexts.
- `nody-wordmark.svg` — horizontal blue symbol and dark wordmark.
- `nody-wordmark-inverse.svg` — horizontal symbol and white wordmark for dark surfaces.

The symbol is an early direction based on Nody's nested workspace/page model. Treat it as a draft until the brand identity is approved.
