Implementation checklist

  • Use semantic landmarks, headings, labels and table headers.
  • Give icon-only controls an accessible name.
  • Expose selected, expanded, checked and disabled states to assistive technology.
  • Support keyboard operation and preserve a logical focus order.
  • Respect reduced motion and browser zoom.
  • Never use color as the only way to communicate status.
